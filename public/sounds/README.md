# Sound Files Guide

Download the following sound files from Pixabay and place them in this folder (`public/sounds/`).

## Required Sound Files

| File Name | Description | Recommended Pixabay Search |
|-----------|-------------|---------------------------|
| `bgm.mp3` | Background music (loop) | [Korean Traditional Music](https://pixabay.com/music/search/korean/) |
| `sfx_throw.mp3` | Yut throwing sound (whoosh) | [Whoosh Sound Effects](https://pixabay.com/sound-effects/search/whoosh/) |
| `sfx_stick_land.mp3` | Stick landing sound | [Wood Block Sound Effects](https://pixabay.com/sound-effects/search/wood-block/) |
| `sfx_yut_mo.mp3` | Yut/Mo celebration sound | [Victory Fanfare](https://pixabay.com/sound-effects/search/victory%20fanfare/) |
| `sfx_catch.mp3` | Catch impact sound | [Punch/Impact Sound Effects](https://pixabay.com/sound-effects/search/punch/) |
| `sfx_goal.mp3` | Goal/finish fanfare | [Fanfare Sound Effects](https://pixabay.com/sound-effects/search/fanfare/) |
| `sfx_move.mp3` | Piece move click sound | [UI Click Sound Effects](https://pixabay.com/sound-effects/search/ui%20click/) |

## Recommended Downloads (Direct Links)

1. **BGM** - [Asian Music Traditional](https://pixabay.com/music/search/asian%20traditional/) - Pick any upbeat track
2. **Throw** - [Whoosh Sound Effect](https://pixabay.com/sound-effects/whoosh-sound-effect-240257/)
3. **Stick Land** - [Wood Block](https://pixabay.com/sound-effects/search/wood%20hit/)
4. **Yut/Mo** - [Crowd Cheer Applause](https://pixabay.com/sound-effects/crowd-cheer-applause-victory-fanfare-clapping-236698/)
5. **Catch** - [Punch](https://pixabay.com/sound-effects/search/punch/)
6. **Goal** - [Success Fanfare](https://pixabay.com/sound-effects/search/success%20fanfare/)
7. **Move** - [Minimal Pop Click UI](https://pixabay.com/sound-effects/minimal-pop-click-ui-1-198301/)

## How to Download from Pixabay

1. Visit the link
2. Click the download button (free account may be required)
3. Choose MP3 format
4. Rename the file to match the required filename
5. Place in `public/sounds/` folder

## Notes

- All Pixabay sounds are royalty-free and don't require attribution
- Keep file sizes small for faster loading (under 500KB for SFX, under 2MB for BGM)
- The game will work without sound files (warnings in console but no crashes)
